# X-UI Deploy Assistant

X-UI Deploy Assistant provides integrated management for users, plans, orders, entitlements, and deployment tasks.

## Installation

Choose the public port in the 1Panel web installer and start the installation. Open the application after it starts. The first visit displays the existing administrator initialization page.

Application data is stored in the `data` directory managed by 1Panel. Keep this directory when upgrading, rebuilding, or migrating the application.

To use a domain and HTTPS, create a website in 1Panel and reverse proxy it to the application's public port.
