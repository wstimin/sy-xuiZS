# X-UI 搭建助手

X-UI 搭建助手提供用户、套餐、订单、权益和搭建任务的一体化管理。

## 使用说明

安装时只需在 1Panel 网页向导中选择访问端口。安装完成后打开应用，首次访问会进入管理员初始化页面，按页面提示创建管理员账号即可开始使用。

应用数据保存在当前 1Panel 应用目录的 `data` 子目录中。升级、重建或迁移时请保留该目录。

需要使用域名和 HTTPS 时，可在 1Panel 中创建网站并反向代理到本应用端口。

## 数据内容

- 管理员和用户账号
- 套餐、面板次数与节点次数
- 订单与支付配置
- 搭建任务与执行记录
- 邮件、客服和首页配置
